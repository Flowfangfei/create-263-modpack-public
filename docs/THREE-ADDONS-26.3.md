# 三个新增模组：版本与试用

本次在原九模组整合包基础上加入三个模组，仍使用 Minecraft Java 26.3、NeoForge 26.3.0.22-beta 和 Java 25。

| 模组 | 本包版本 | 主要用途 |
| --- | --- | --- |
| Create Liquid Fuel | 3.0.0-26.3-adapted.1 | 给 Create 烈焰人燃烧室增加原生流体入口，以数据映射定义普通/超热燃料。 |
| Create Ore Excavation | 1.6.8-26.3-adapted.1 | 矿脉定位、图册、取样、钻井和抽液，多方块机器连接 Create 动力。 |
| Transmission & Linkage | 0.2.8-26.3-adapted.1 | 万向节、液压连杆、铰链、动能转换及设置界面，依赖本包的 Sable/Simulated。 |

## 导入与开始

运行新版安装器中的 `Install-Pack.cmd`，再把生成的 `Create263-Pack-v0.2.0-alpha.1-HMCL.zip` 作为新整合包导入 HMCL，选择 Java 25。旧版实例继续独立保管。完整生成包和安装器位置见根目录 [README](../README.md)。

在新建创造模式世界中打开对应物品分类。测试命令需要世界允许命令；服务端控制台的 `time query gametime` 成功并不自动授予普通玩家权限。

- 液体燃料：放置装有烈焰人的燃烧室，使用熔岩桶，或用机械泵和管道供给熔岩，观察火焰变为正常加热。储液上限为1000mB，完整容器放不下时拒绝接收并保留物品。可重复使用容器会返还抽取后的实际余物和组件。
- 矿脉钻井：用取样钻与背罐/矿脉图册确认矿脉，再放置完整钻井或抽液机器，装入相应钻头并接上动力。产出取决于矿脉配方、转速、应力和所需流体；机器出现并不代表所在区块一定有适用矿脉。
- 传动与连杆：查看液压杆物品的 Ponder 场景，在地面与已装配的 Sable 子空间之间连接两端，再调节预期长度、恢复力或角度。大量约束和复杂闭环仍属于进一步玩法测试范围。

默认液体燃料沿用上游熔岩规则及其已有的可选模组映射；本次没有擅自给 Diesel 的每种油料设定新的热值。联合测试使用的“水燃料”只存在于临时测试世界的数据包，游玩包不包含这条规则。测试 Diesel 罐验证的是容器事务，不等同于已给全部 Diesel 流体配置燃料。

## 源码与验证入口

三个模块均在 `modules/`，使用 [共享平台](../gradle/create263-addon.gradle) 和 [串行构建工具](../scripts/gradle_serial.py)。各自的上游提交、代码变化及许可分别记录于模块的 `docs/PORTING-26.3.md` 和根目录 [来源清单](../manifests/sources.json)。

实际通过的功能、保存与重载、客户端画面，以及尚未覆盖的边界见 [联合验证记录](VALIDATION.md)。矿脉模块的 JEI、KubeJS、CC:Tweaked、JourneyMap 可选联动源码保留，目前不进入运行构建。Toolgun蓝图保存联动未随包提供或验证。传动与连杆的非商业及附带许可仍独立适用，见 [第三方声明](../THIRD_PARTY_NOTICES.md)。
