## Create: Dragons Plus 1.11.8 — Minecraft 26.1.2

### Added

* Added a dedicated Automated Coloring JEI category for Mechanical Mixer recipes that use dye fluids. Dye items and equivalent items in their dye tags can now find both Automated Coloring and Bulk Coloring recipes, with rotating dye-bucket icons for both categories.

### Fixed

* Fixed rare package models loading too late, which could crash the client when rare packages were placed.

### Compatibility

* Optional NeoForge integrations, including Ars Nouveau and Aether, remain unavailable in the Create-Fly build.
